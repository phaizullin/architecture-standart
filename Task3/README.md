## Ключевые архитектурные решения

### 1. API Gateway
Новый компонент на .NET Core для:
- Разгрузки АБС от прямых подключений
- Централизации API для всех клиентских приложений
- Кэширования часто запрашиваемых данных
- Обеспечения производительности (отклик <1 сек)

### 2. Сервис управления ставками
Новый сервис на Java Spring Boot для:
- Замены Excel-процессов системным решением
- Управления актуальными ставками по депозитам
- Интеграции с API Центробанка
- Разделения доступа между отделами

### 3. Минимальные изменения существующих систем
- Интернет-банк: только новые API для подачи заявок
- АБС: только новые API для получения заявок
- Кол-центр: интеграция с сайтом через существующие API

## Технологический стек

- **API Gateway**: .NET Core (совместимость с интернет-банком)
- **Сервис ставок**: Java Spring Boot (экспертиза команды АБС)
- **Базы данных**: MS SQL для новых сервисов
- **Интеграция**: REST API
- **Безопасность**: HTTPS для всех веб-интерфейсов

## Преимущества решения

- **Быстрая реализация** - минимум изменений в существующих системах
- **Масштабируемость** - API Gateway готов к росту нагрузки
- **Безопасность** - разделение доступов и HTTPS
- **Производительность** - кэширование и оптимизация запросов
- **Поддерживаемость** - использование знакомых технологий
