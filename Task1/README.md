## Ключевые выводы

### Что мешает сделать депозиты полностью цифровым продуктом:

1. **Технические проблемы**:
   - Прямой доступ интернет-банка к БД АБС (риск перегрузки)
   - Отсутствие API-слоя для безопасной интеграции
   - Монолитная архитектура интернет-банка

2. **Процессные проблемы**:
   - Ручной расчет ставок в Excel
   - Общение между подразделениями через Email
   - Отсутствие автоматизированного workflow

3. **Интеграционные проблемы**:
   - Нет интеграции с партнерским кол-центром
   - Разрозненность систем
   - Отсутствие единого источника данных для ставок

## Рекомендации для цифровой трансформации

### Краткосрочные меры (3-6 месяцев):
1. Внедрить API Gateway для безопасной интеграции
2. Автоматизировать расчет ставок в АБС
3. Создать интеграцию с партнерским кол-центром

### Долгосрочные меры (6-12 месяцев):
1. Перейти на микросервисную архитектуру для интернет-банка
2. Внедрить систему управления бизнес-процессами (BPM)
3. Создать единую платформу для управления продуктами
