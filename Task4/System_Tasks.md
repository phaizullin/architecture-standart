# Задачи для интеграции кол-центров с системой ставок

Последовательность выполнения и временные рамки указаны в roadmap.

| № | Название задачи | Описание | Основные задачи |
|---|---|---|---|
| 1 | Доработка сервиса управления ставками | Расширить существующий сервис ставок функциями для работы с кол-центрами. Добавить REST API для получения актуальных ставок и настроить автоматическую рассылку обновлений. | • Создать API endpoint <br>• Реализовать фильтрацию ставок<br>• Добавить автоматическую отправку обновлений<br>• Настроить кэширование для снижения нагрузки |
| 2 | SFTP Gateway для партнерского кол-центра | Создать компонент для автоматической передачи файлов с актуальными ставками партнерскому кол-центру по SFTP. Партнер может работать только с файлами. | • Настроить SFTP-соединение с партнером<br>• Реализовать генерацию CSV-файлов<br>• Добавить автоматическую отправку файлов<br>• Создать проверку доставки и уведомления |
| 3 | Интеграция с системой внутреннего кол-центра | Интегрировать систему кол-центра с API ставок. Операторы должны видеть актуальные ставки в своем интерфейсе при консультировании клиентов. | • Добавить вызов API ставок в систему<br>• Создать интерфейс отображения ставок<br>• Реализовать кэширование данных<br>• Добавить обработку ошибок |
| 4 | Система мониторинга и уведомлений | Создать систему для мониторинга передачи ставок в кол-центры и уведомлений о сбоях. Нужен контроль работы всех интеграций. | • Логирование всех операций передачи<br>• Email-уведомления при сбоях<br>• Простой веб-дашборд для контроля<br>• Настроить алерты в мониторинг |
| 5 | Настройка инфраструктуры | Подготовить инфраструктуру для новых интеграций. Настроить сетевые подключения, обновить мониторинг и бэкапы. | • Настроить сетевые подключения<br>• Обновить схемы резервного копирования<br>• Добавить новые сервисы в мониторинг<br>• Настроить файрволы и безопасность |
| 6 | Интеграционное тестирование | Протестировать работу всех интеграций между системами. Проверить сценарии сбоев и восстановления. | • Тестирование API интеграции<br>• Проверка SFTP-передачи файлов<br>• Тестирование сценариев сбоев<br>• Проверка производительности |
| 7 | Приемочное тестирование и запуск | Финальное тестирование с участием реальных операторов кол-центров. Обучение операторов работе с новым функционалом. | • Тестирование с реальными операторами<br>• Обучение операторов новому интерфейсу<br>• Проверка всех бизнес-сценариев<br>• Финальные доработки и запуск |

## Зависимости между задачами

**Критический путь:**
- Задача 1 → Задача 3 (нельзя интегрировать кол-центр без готового API)
- Задача 6 зависит от задач 1-5
- Задача 7 зависит от задачи 6

**Параллельное выполнение:**
- Задача 2 (SFTP) выполняется параллельно с задачей 3
- Задача 4 (мониторинг) может выполняться параллельно с задачами 2-3
- Задача 5 (инфраструктура) выполняется в начале параллельно с задачей 1

## Основные риски

- Подрядчик кол-центра затянет интеграцию. Решение: можем запустить сначала только SFTP для партнера

- SFTP с партнером не заработает сразу. Решение: Временно отправлять файлы вручную
- Нагрузка на сервис ставок больше ожидаемой. Решение: Использовать кэширование и оптимизацию
- Проблемы с безопасностью при передаче данных. Решение: Тщательная проверка всех соединений
