# Задание 2. FURPS+ таблица требований для MVP открытия депозитов

## Описание

Таблица содержит 18 ключевых требований к MVP системы онлайн-открытия депозитов, структурированных по методологии FURPS+.

## Основные требования

### Функциональные (F1-F5)
- Подача заявок через сайт и интернет-банк
- СМС-подтверждения (используем существующий функционал)
- Отображение актуальных ставок (замена Excel)
- Интеграция с кол-центром

### Удобство использования (U1-U2)
- Простой интерфейс для пожилых клиентов
- Корпоративный дизайн

### Надежность (R1-R2)
- Стандартная доступность 99.9%
- Использование резервного ЦОД

### Производительность (P1-P2)
- Отклик не более 1 секунды (решение текущей проблемы)
- Не перегружать АБС

### Поддерживаемость (S1-S3)
- Использование существующих технологий (MS SQL, Oracle, .NET, Java)
- Развитие без изменения ядра интернет-банка

### Ограничения (+R1-+R4)
- HTTPS для защиты данных
- Соответствие требованиям ЦБ
- Разделение доступа между отделами
- Работа в существующей инфраструктуре

Требования решают основные проблемы из анализа IT-ландшафта:
- **Excel-процессы** → Системное управление ставками (F4)
- **Перегруженная БД АБС** → Оптимизация производительности (P2)
- **Ограничения подрядчика** → Развитие без изменения ядра (S3)
